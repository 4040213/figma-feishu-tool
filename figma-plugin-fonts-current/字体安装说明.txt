Figma 题目生成插件字体包（当前电脑）
==================================

一、插件当前实际使用的字体

1. 方正粗圆简体.TTF
   - 字体族：方正粗圆简体
   - 插件名称兼容：方正粗圆简体 / FZCuYuan-M03S
   - 用途：中文题干、选项、负反馈和小灯泡正文

2. times.ttf
   - 字体族：Times New Roman
   - 用途：英文、数字和拉丁字母正体

3. timesi.ttf
   - 字体族：Times New Roman Italic
   - 用途：变量、希腊小写字母以及 Word 中明确设置为斜体的内容

4. simsun.ttc
   - 字体族：宋体 / 新宋体（SimSun / NSimSun）
   - 用途：中文标点和部分通用符号

5. cambria.ttc
   - 字体族：Cambria / Cambria Math
   - 用途：数学运算符和公式符号

二、备用字体

6. msyh.ttc
   - 字体族：微软雅黑 / Microsoft YaHei
   - 用途：方正粗圆不可用时的第一备用中文字体
   - 为了保证同事电脑字体未正确识别时插件仍可生成，随包附带。

三、安装方法

1. 关闭 Figma 桌面端。
2. 选中本文件夹内全部 .TTF / .ttf / .ttc 文件。
3. 右键选择“为所有用户安装”；没有管理员权限时选择“安装”。
4. 重新启动 Figma 桌面端后再运行插件。
5. 如果使用浏览器版 Figma，还需要启动 Figma Font Installer / Font Helper。

四、注意事项

- 插件会优先使用“方正粗圆简体”，因此同事电脑必须安装该字体才能获得一致的中文效果。
- Times New Roman、宋体、Cambria Math 和微软雅黑通常随 Windows 提供，但仍建议按本包统一安装或核对版本。
- 字体文件可能受各自授权条款限制。请仅在你们单位已有合法授权、且内部共享符合许可的情况下分发和使用。
